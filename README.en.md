# Elyne Next

**Languages: English · [Français](README.md)**  
**Catalog status: Preview**

A resident local AI that separates its inference model from persistent memory, documents, and history.

## Presented capabilities

- Durable memory, lexical and dense retrieval, sources, and revisable beliefs.
- Resume after interruption, consolidation, and reflection during rest periods.
- Local tools used within authorized scopes.

## Scope

The website lists Next as Preview. The local technical sheet is dated 17 September 2026 and describes a particular model configuration; this repository does not claim it matches the current runtime or is validated on every machine.
